# Capability Catalog: Javi Morala

## Capabilities

### Primary

- **id:** `hero-presentation`
  **name:** Hero Presentation
  **definition:** Deliver an immediate, high-impact first impression of Javi's
  identity and value to any visitor arriving at the site.

- **id:** `about-narrative`
  **name:** About Narrative
  **definition:** Present Javi's authentic professional and personal identity
  through structured bio content.

- **id:** `contact-links`
  **name:** Contact Links
  **definition:** Provide direct links to external contact channels (email,
  social) so an interested visitor can reach Javi.

- **id:** `localization`
  **name:** Localization
  **definition:** Present all site content in the visitor's language (English
  or Spanish), auto-detected from browser locale by default, with an
  always-available manual override.

### Supporting

- **id:** `section-navigation`
  **name:** Section Navigation
  **definition:** Let a visitor move directly between sections via a
  persistent nav — inline on desktop, overlay on mobile — as a shortcut
  alongside free scrolling. Enables the primary capabilities rather than
  standing as an end goal in itself.

## Excluded

- **Motion & Interaction** — not a capability. It has no independent,
  visitor-initiated outcome; it describes *how* every capability above is
  presented (bold section-level motion, restrained micro-interactions,
  mandatory reduced-motion fallback), the same level as Project UX's other
  UX Constraints (contrast, dark-only, performance). Already captured there;
  not duplicated in this catalog.
